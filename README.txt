TYCOON TOWN - app files
=======================
Files: index.html, manifest.webmanifest, sw.js, icons/ (keep this folder structure).

PUT IT ONLINE (GitHub Pages)
1. Upload ALL of these files and the icons folder to the root of a GitHub repo.
2. Repo Settings > Pages > deploy from the main branch (root).
3. Open the Pages link on each device.

INSTALL ON A TABLET OR PHONE
- iPad/iPhone (Safari): Share button > Add to Home Screen.
- Android (Chrome): menu > Install app (or Add to Home screen).
It then opens full screen with its own icon and works offline for solo/CPU games.

PLAYING ONLINE
Host taps Play online > Host a room and shares the 5-letter code.
Others open the app, tap Play online, enter the code, tap Join room.
Online play needs internet; it works best when everyone is on the same Wi-Fi.

UPDATING
After uploading a new index.html, change the version in sw.js (tycoon-v1 > tycoon-v2)
so devices pick up the new version.
